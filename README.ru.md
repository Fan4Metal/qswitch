<p align="center"><a href="README.md">English</a> | <b>Русский</b></p>

qswitch — это небольшой переключатель раскладки клавиатуры для Windows для тех, кто пишет на двух языках, в духе Punto Switcher и Caramba Switcher. Слово, набранное не в той раскладке (`ghbdtn` вместо `привет`, `зкштеа` вместо `printf`), исправляется двумя нажатиями Shift: слово заменяется теми же клавишами, прочитанными в другой раскладке, а окно переключается на эту раскладку. Программа живёт в области уведомлений, показывает там текущую раскладку и следует правилам для отдельных программ. Набранное не записывается на диск и никуда не отправляется.

![Страница «Состояние» qswitch: состояние, раскладка и программа впереди, поле для пробы жеста](images/screenshot.png)

*Снимок окна версии 0.1.1 (английский интерфейс).*

## Возможности

- **Два нажатия Shift**: последнее слово переводится в другую раскладку, и раскладка переключается (см. [Жест](#жест)). Тот же жест, повторённый, возвращает слово как было, и раскладку тоже.
- **Выделенный текст**: если ничего не набрано, жест переводит выделение — в любой программе, которая отдаёт свой текст через UI Automation (редакторы, браузеры, Office, мессенджеры).
- **Автопереключение**, по желанию: слово, набранное не в той раскладке, переводится само по пробелу после него; решает статистика букв двух языков, ошибочная замена отменяется жестом (см. [Автопереключение](#автопереключение)).
- **Caps Lock как переключатель раскладки**: по желанию; Shift+Caps Lock остаётся обычным Caps Lock.
- **Раскладка в области уведомлений**: две буквы (`EN`, `RU`) цветом панели задач, на синем квадрате при включённом автопереключении, на красном при включённой трассировке клавиш или списке преобразований, серые во время паузы.
- **Метка у курсора ввода**: буквы раскладки на миг появляются под кареткой при каждой смене раскладки или постоянно следуют за ней, в выбранном размере и цвете (см. [Метка у курсора ввода](#метка-у-курсора-ввода)).
- **Правила для программ**: не вмешиваться в играх и удалённых рабочих столах, начинать программу в заданной раскладке (см. [Программы](#программы)).
- **Любая пара установленных раскладок**, не только английская и русская.
- **Светлая, тёмная или системная тема.**
- **Русский и английский интерфейс**: язык следует за языком Windows и меняется в окне «О программе» (`F1`).
- **Портативность**: [портативный архив](#установка) хранит настройки рядом с программой.
- **Конфиденциальность**: набранное не хранится на диске; программа не обращается к сети, кроме необязательной проверки обновлений (см. [Проверка обновлений и конфиденциальность](#проверка-обновлений-и-конфиденциальность)).

## Установка

Установщик и портативный архив публикуются на странице [Releases](https://github.com/Fan4Metal/qswitch/releases). Исполняемые файлы не подписаны, поэтому при первом запуске Windows SmartScreen может предупредить о неизвестном издателе.

- **Установщик** `qswitch_<версия>_Setup.exe`: не требует прав администратора; программа помещается в `%LOCALAPPDATA%\Programs\qswitch` и хранит настройки в `%APPDATA%\qswitch`. Он предлагает запускать программу вместе с Windows (та же настройка есть на странице «Настройки»).
- **Портативный архив** `qswitch_<версия>_portable.zip`: программа в папке `qswitch`, работает без установки; настройки хранятся рядом с ней, так что её можно носить на съёмном диске.

<details>
<summary>Где портативная программа хранит настройки</summary>

В архиве лежит пустой файл `qswitch.json`. Пока он находится рядом с `qswitch.exe` и папка доступна для записи, настройки хранятся в нём. Без этого файла настройки хранятся в `%APPDATA%\qswitch`, как у установленной программы. Окно «О программе» показывает, где хранятся настройки.

</details>

## Жест

Программа следит за клавишами, набранными с последнего перемещения курсора (щелчок, стрелка, Enter, смена окна), и знает, что каждая из них вывела на экран в любой из двух раскладок пары. Два нажатия Shift подряд, без других клавиш между ними, делают следующее:

| Нажатие | Действие |
|---|---|
| Первое | Последнее слово стирается и набирается заново теми же клавишами, прочитанными в другой раскладке; окно переключается на эту раскладку. |
| Второе | Слово возвращается как было набрано, раскладка тоже. Каждый следующий повтор снова переводит его. |

На странице «Состояние» есть поле, в котором жест можно попробовать: слово, набранное в нём не в той раскладке, преобразуется так же, как где угодно. Вместо двух нажатий Shift на странице «Настройки» можно выбрать два нажатия Ctrl или клавишу Pause/Break (как в Punto Switcher).

<details>
<summary>Выделенный текст и жест, когда ничего не набрано</summary>

Если ничего ещё не набрано, жест переводит выделенный текст, когда он есть: выделение читается через UI Automation, переводится посимвольно (каждый символ уходит в другую раскладку пары) и впечатывается поверх выделения, а окно переключается на раскладку результата. Если нет и выделения, жест только переключает раскладку. Программы, не отдающие свой текст (и терминалы, где набор не заменяет выделение), получают только переключение раскладки.

</details>

<details>
<summary>Как впечатывается преобразование и где жест не действует</summary>

Преобразование выполняется стиранием символов перед курсором клавишей Backspace и набором новых как Unicode, поэтому работает в любой программе, принимающей ввод с клавиатуры: редакторах, браузерах, мессенджерах, терминалах. Программы, обрабатывающие клавиши сами (игры с DirectInput, удалённые рабочие столы, виртуальные машины), лучше исключить правилом (см. [Программы](#программы)); удалённый рабочий стол, VirtualBox, VMware и Hyper-V исключены изначально. Окна программ, запущенных от имени администратора, не принимают ввод от программы без таких прав, поэтому там жест не действует, если qswitch сам не запущен от имени администратора.

</details>

## Автопереключение

Выключенное, пока не включено (кнопка **Авто** в панели инструментов или страница «Настройки»), автопереключение переводит слово, набранное не в той раскладке, по пробелу после него, как это сделал бы жест, и переключает раскладку: `ghbdtn ` становится `привет `, `руддщ ` — `hello `. Ошибочная замена отменяется жестом, и это слово больше не трогается до перезапуска программы. Настройка **Уверенность** выбирает между долей пойманных слов и редкой ошибкой: осторожно, обычно (по умолчанию) или смело. Работает для пары английской и русской раскладок.

<details>
<summary>Как принимается решение и что не трогается</summary>

У каждого языка есть таблица стоимости каждого сочетания трёх букв, построенная по частотному списку слов (`tools/make_ngrams.py`) и вшитая в программу (60 КБ на оба языка). Слово читается в раскладке, в которой набрано, и в другой; когда чтение в другой раскладке стоит намного меньше и само по себе правдоподобно, слово переводится. На словах, которых таблицы не видели, настройка «смело» ловит 95 % слов, набранных не в той раскладке, и ошибается на 0,04 % слов, набранных верно; «осторожно» ловит около 70 % и не ошибается.

Ничего не переводится в полях паролей (классическом поле пароля или элементе, который UI Automation называет паролем) и в терминалах, где набранный пароль не виден. Слова короче трёх букв, слова с цифрами или знаками пути, адреса и кода (`/ \ @ : # & = % + _ ~ ^ | < > ( ) [ ] { } * $`), а также слова, уже перевёрнутые жестом, не трогаются, как и слова, возвращённые жестом (хранятся только в памяти). Слово перед Enter не проверяется: в чате Enter его отправляет.

</details>

## Метка у курсора ввода

При смене раскладки, жестом или по Alt+Shift, под кареткой окна впереди на 0,7 с появляется маленькая метка с буквами раскладки, так что раскладка видна там, куда смотрят глаза, а не в углу экрана. На странице «Настройки» три режима: нет, на миг при смене раскладки (по умолчанию, с настройкой времени показа) или всегда, рядом с курсором. Метка не забирает фокус и пропускает щелчки сквозь себя.

<details>
<summary>Размер, цвета и предпросмотр</summary>

Размер букв метки задаётся на странице «Настройки» (по умолчанию 10 пт), и метке можно дать свой цвет для каждой раскладки пары (синий и красный, пока не выбраны другие) вместо серого цвета панели задач, так что раскладка узнаётся по цвету раньше, чем прочитаны буквы. Пока что-то из этого меняется, а также по кнопке «Показать», метка показывается рядом с указателем, так что вид виден сразу.

</details>

<details>
<summary>Установка курсора и поиск каретки</summary>

В режиме «на миг» метка также появляется при установке курсора: щелчке в текст, переходе в другое поле или окно (флажок, включён по умолчанию); щелчок по тому, что не принимает текст, ничего не показывает. В режиме «всегда» метка так же следует за кареткой через щелчки и смену окна и уходит, когда фокус переходит на то, что текст не принимает.

Её место берётся из каретки, о которой программа впереди сообщает Windows (Блокнот, Office и большинство классических программ); у программ, рисующих каретку сами (Chrome, Edge, VS Code и другие приложения на Electron, приложения WPF и из Store), оно запрашивается через специальные возможности (UI Automation), что занимает несколько миллисекунд. Лишь когда не отвечает ни то, ни другое, метка появляется рядом с указателем мыши.

</details>

## Программы

Страница «Программы» содержит правила по имени исполняемого файла программы:

| Поведение | Значение |
|---|---|
| Не вмешиваться | Пока впереди окно этой программы, жест выключен и ничего не отслеживается. |
| Начинать в EN / Начинать в RU | Когда окно программы выходит вперёд, оно переводится в эту раскладку; жест работает как обычно. |

Список под правилами предлагает программы, у которых сейчас есть окно на экране; первой — та, что была впереди до открытия окна qswitch, так что правило для игры или терминала создаётся без ввода имени её exe.

## Пауза и область уведомлений

Щелчок по значку только переключает раскладку окна, которое было впереди, а фокус остаётся на месте; собственное окно qswitch открывается из меню значка, в котором — **Показать**, **Пауза** (все клавиши проходят как есть, значок становится серым), **Автопереключение** (с галочкой, пока включено) и **Выход**. Кнопка закрытия окна и клавиша Esc прячут его в область уведомлений (настройка на странице «Настройки»); программа завершается из меню значка.

<details>
<summary>Командная строка</summary>

Повторный запуск `qswitch.exe` лишь выводит вперёд окно работающей копии. `qswitch.exe --pause`, `--resume` и `--quit` передают работающей копии команду (для скриптов и игровых лаунчеров); `--hidden` запускает её без окна (запись автозапуска); `--version` и `--help` печатают в консоль.

</details>

| Клавиша | Действие |
|---|---|

## Проверка обновлений и конфиденциальность

Проверка обновлений необязательна и по умолчанию выключена. Если в окне «О программе» включён флажок **Проверять обновления при запуске (раз в сутки)**, программа не чаще раза в сутки запрашивает у GitHub Releases API (`api.github.com`) последний выпуск; кнопка **Проверить сейчас** в том же окне делает запрос немедленно. Запрос не содержит ничего, кроме версии программы в заголовке `User-Agent`; ничего не скачивается и не устанавливается: если есть более новый выпуск, рядом с кнопкой «О программе» появляется кнопка с его версией, открывающая страницу выпуска в браузере. В остальном программа к сети не обращается.

Набранные клавиши хранятся в памяти лишь пока их ещё можно преобразовать (до перемещения курсора) и никогда не записываются на диск; список последних преобразований на странице «Состояние» выключен, пока не включён его флажок, живёт в памяти, пока включён, и исчезает вместе с программой. Единственное исключение — флажок на странице «Состояние», записывающий трассировку клавиш в файл рядом с настройками, чтобы разобраться, что программа делает с преобразованным текстом; при каждом запуске он выключен. Пока включено то или другое, панель инструментов сообщает об этом красным, и значок в области уведомлений становится красным: пароли набираются и преобразуются как любые другие слова.

## Сборка

Требования: Windows 10 или новее, стабильный Rust (цель MSVC, редакция 2024) и Visual Studio 2022 Build Tools с компонентами C++. Для `build.py` нужен [uv](https://docs.astral.sh/uv/).

```
uv run build.py          # target\release\qswitch.exe
cargo test
```

<details>
<summary>Как устроена сборка</summary>

`build.py` сначала закрывает `qswitch.exe`, запущенный из папки `target` проекта (иначе файл заблокирован), затем выполняет `cargo build --release`. Если программа не запущена, достаточно и обычного `cargo build --release`. Исполняемый файл линкует среду выполнения C статически (`.cargo/config.toml`), поэтому ему не нужно ничего, кроме самой Windows.

</details>

<details>
<summary>Настройка окружения</summary>

Инструменты ставятся через winget:

```
winget install Rustlang.Rustup Microsoft.VisualStudio.2022.BuildTools Python.Python.3.12 astral-sh.uv JRSoftware.InnoSetup
```

В Visual Studio Installer у Build Tools выбирается рабочая нагрузка C++ («Разработка классических приложений на C++»).

</details>

## Установщик и выпуск

Скрипт выпуска собирает исполняемый файл, установщик и портативный архив. Ему нужен [Inno Setup 6](https://jrsoftware.org/isinfo.php).

```
python tools/make_release.py              # тесты, release-сборка, установщик, архив
python tools/make_release.py --no-tests   # то же без cargo test
python tools/make_release.py --install    # затем тихая установка поверх установленной копии
```

Скрипт записывает файлы в `dist`, версия берётся из `Cargo.toml`. Скрипт установщика — `tools/setup.iss`; значок установщика записывает `qswitch.exe --export-icon <файл.ico>`.

<details>
<summary>Выпуски на GitHub</summary>

Выпуски на GitHub собирает workflow **Release** (`.github/workflows/release.yml`). После обновления версии в `Cargo.toml` и коммита отправка соответствующего тега публикует выпуск с установщиком и портативным архивом:

```
git tag v0.1.0
git push origin v0.1.0
```

Workflow останавливается, если тег не совпадает с версией в `Cargo.toml`. Ручной запуск (Actions → Release → Run workflow) собирает файлы и прикладывает их к запуску, не создавая выпуска.

</details>

## Используемые проекты

qswitch построен на следующих проектах с открытым исходным кодом:

- [egui / eframe](https://github.com/emilk/egui): интерфейс и окно;
- [serde](https://serde.rs/) и [serde_json](https://github.com/serde-rs/json): файл настроек;
- [FrequencyWords](https://github.com/hermitdave/FrequencyWords) (частотные списки слов из OpenSubtitles, CC BY-SA 4.0): по ним построена статистика букв автопереключения;
- [Inno Setup](https://jrsoftware.org/isinfo.php): установщик.
